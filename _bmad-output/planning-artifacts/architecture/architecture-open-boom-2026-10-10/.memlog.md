- (constraint) Inherited PRD requirement: zero kernel-mode drivers (.sys); 100% user-mode WASAPI capture to prevent BSODs and eliminate driver signing expenses.
- (constraint) Inherited from ADR-001/ADR-004: OpenBoom lives in separate repository open-boom, using sibling decompilator and global REA MCP for reverse engineering verification.
- (constraint) Inherited from PRD SM-1 & NFR: Total round-trip audio latency < 15ms at 48 kHz 32-bit float; zero heap allocations or blocking locks on the real-time audio thread.
- (constraint) Inherited from PRD SM-3: Idle memory footprint < 40 MB RAM; active DSP CPU usage < 2.0% on standard 64-bit multi-core processors.
- (constraint) Inherited from PRD SM-6: Master Peak Limiter enforced at -0.2 dBFS lookahead to prevent inter-sample digital clipping across all volume and EQ combinations.
- (direction) Adopt Pipes-and-Filters / Hexagonal Ports-and-Adapters paradigm: Real-Time Audio Pipeline is fully decoupled from the UI control plane via lock-free SPSC ring buffers.
- (decision) AD-1 (Real-Time Audio Thread Invariants & Lock-Free Boundary): Binds: audio_engine, dsp_pipeline, all filter modules. Prevents: priority inversion, GC pauses, audio dropouts. Rule: Audio callback thread executes under Windows MMCSS "Pro Audio" scheduling; strictly zero heap allocations, zero blocking mutexes, zero file/socket I/O. UI dispatches commands to an atomic SPSC ring buffer.
- (decision) AD-2 (Driverless Loopback Capture & Feedback Isolation): Binds: audio_capture, device_router. Prevents: acoustic feedback loops and kernel driver requirements. Rule: Windows 10 (20348+) and Windows 11 use AUDIOCLIENT_PROCESS_LOOPBACK_PARAMS with PROCESS_LOOPBACK_MODE_EXCLUDE_PROCESS_TREE excluding OpenBoom own PID. Fallback to Virtual Audio Cable adapter for legacy Windows 10 builds.
- (decision) AD-3 (Unified 48kHz Float32 Internal Processing Pipeline): Binds: dsp_pipeline, all DSP stages. Prevents: sample rate drift, format conversion thrashing, intermediate clipping. Rule: All DSP stages operate on 32-bit floating point PCM at fixed 48,000 Hz. Sample rate and channel re-mapping occur strictly at capture and render boundaries.
- (decision) AD-4 (Single Source of Truth for State & Parameter Smoothing): Binds: ui_controller, state_manager, dsp_pipeline. Prevents: parameter race conditions, zipper noise, and UI-DSP state drift. Rule: UI maintains presentation state; changes are emitted as immutable parameter delta events. Audio engine consumes events and applies linear interpolation (10ms ramp) to parameter updates.
- (decision) AD-5 (Safety-First Master Lookahead Peak Limiter): Binds: dsp_pipeline, master_limiter. Prevents: hearing damage and digital clipping distortion. Rule: The Master Lookahead Peak Limiter is the mandatory terminal filter in the DSP graph, clamping true peaks at -0.2 dBFS with a 2ms lookahead buffer and fast release; it cannot be disabled by user presets.
- (decision) AD-6 (Parametric AutoEq Compensation & Dynamic Preamp Offset): Binds: autoeq_engine, eq_stage, preamp_stage. Prevents: clipping caused by positive EQ gain boosts in headphone calibration curves. Rule: AutoEq profiles are evaluated as biquad filter banks (peaking/shelving). When total peak gain exceeds 0 dB, preamp stage automatically applies an equal negative offset (-max(0, peak_gain_db)).
- (decision) AD-7 (Decoupled Engine Core & UI Shell Architecture): Binds: project_structure, build_system, packaging. Prevents: monolithic coupling between UI framework and real-time audio core. Rule: The system is structured into open-boom-core (native low-latency C++/Rust audio processing engine exposing C-ABI / IPC) and open-boom-ui (modern dark Fluent desktop shell). [ASSUMPTION: Modular core-engine and UI boundary]
- (decision) AD-8 (Per-Process Session Mixer via IAudioSessionManager2): Binds: session_mixer, windows_audio_adapter. Prevents: conflicting system mixer overrides and unauthorized process control. Rule: Process audio volume and mute are managed through Windows Core Audio IAudioSessionManager2 without injecting DLLs into external processes.
- (decision) AD-9 (Offline-First Bundled AutoEq Database): Binds: autoeq_engine, storage. Prevents: runtime network dependency, API rate limits, and latency during profile lookup. Rule: Over 4,000 headphone calibration profiles are bundled into a compressed binary/JSON index (<5 MB) loaded into memory at startup with fast in-memory prefix search.
- (decision) AD-10 (JSON Configuration & Atomic Persistence): Binds: storage, settings_manager, preset_manager. Prevents: corrupted configuration files upon sudden system shutdown or crash. Rule: All presets and application settings are persisted to %APPDATA%/OpenBoom/ as JSON via write-to-temp-then-atomic-rename.
