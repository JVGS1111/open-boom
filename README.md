# OpenBoom

Open-source 3D audio enhancer, parametric equalizer, and real-time DSP suite for Windows, inspired by Boom 3D.

## Features
- **3D Spatial Surround:** Binaural spatialization and virtual 5.1/7.1 speaker simulation for headphones.
- **AutoEq Database:** Integrated calibration curves for thousands of headphone models.
- **Multi-band Equalizer:** Graphic and parametric EQ with custom presets.
- **Audio Enhancement Suite:** Real-time Ambience (Reverb), Fidelity (Harmonic Exciter), Night Mode (DRC), Spatial widening, and Pitch control.
- **Per-Application Volume Mixer:** Dedicated control over individual running Windows apps.
- **Modern Fluent UI:** High-fidelity dark theme with tactile dials, live spectrum visualizer, and low-latency response.

- `.bmad/02-MILESTONES.md`: Step-by-step milestones.
- `.bmad/03-TASK-BACKLOG.md`: Granular task tracking.
- `.bmad/04-DECISION-LOG.md`: Architectural Decision Records (ADRs).
- `.bmad/05-SESSION-STATE.md`: Active context and immediate next steps.
